# 后续优化：Obsidian Knowledge Bridge

当前状态：**第五阶段“本地知识提炼与复用”已完成**。

## 优化目标

在不改变 Jarvis Core 主数据边界的前提下，将 Obsidian 接入为本地、
可阅读、可审计的长期知识层。

## 产品边界

- PostgreSQL 仍是任务、记忆、情报、提醒和投资数据的唯一事实来源；
- Obsidian 保存知识笔记和长期复盘，不保存密钥或通知执行状态；
- 首版不依赖社区插件、独立 MCP、Qdrant 或 Obsidian Sync；
- Vault 未配置或暂时不可用时，现有 Jarvis 功能不受影响。

## 验收标准

- Vault 未配置时 API、网页、提醒和情报继续正常运行；
- 非法路径、隐藏配置目录和越界路径被拒绝；
- 能搜索并打开用户手工创建的 Markdown；
- 同一条记忆或同一份日报重复归档不会生成重复文件；
- 用户在 Obsidian 修改文件后，重新扫描不会被旧内容覆盖；
- API 自动化测试、前端类型检查、lint 和构建全部通过。

## 后续可选增强

- 为大规模笔记增加本地向量检索；当前规模继续使用词法检索；
- 增加候选合并、编辑和来源对照视图；当前可确认或忽略；
- 增加冲突合并界面；当前先保留原文件并把 Jarvis 新版本写入 `_review/`；
- 手机端成熟后提供只读知识浏览，不直接开放 Vault 写权限。
