# Sprint 20：Voice Persona

## 目标

让 Jarvis 的主动提醒拥有稳定、克制、可辨认的中英文男声，同时保留可靠的系统
语音降级。此阶段实现的是原创 Jarvis 风格，不复制电影演员或配音演员的声纹。

## 已完成

- 接入离线中文男声 `vits-zh-hf-fanchen-wnj`；
- 接入离线美式英语男声 `vits-piper-en_US-hfc_male-medium`；
- 中文、英文和中英混合文本自动识别，混合内容按原顺序分段合成；
- 两种声线采用统一 22.05 kHz 输出，并在语言切换处加入极短自然停顿；
- 模型只在本机 CPU 上推理，不占用 RTX 3050 的 4 GB 显存；
- 新增自动、本地男声和 Windows 系统语音三种引擎选项；
- 新增沉稳、简洁和朴素三种播报人格；
- 根据提醒、情报、英语复习、成长任务和系统状态生成不同开场语；
- 播报前清理 Markdown、链接和不适合朗读的长文本；
- 高优先级提醒使用更明确的措辞和略快语速；
- Windows 系统语音作为自动降级，不因本地模型故障丢失提醒；
- Desktop Companion 分别上报中文男声、英语男声、双语链路和系统语音状态；
- 提醒页可查看当前引擎、选择人格、调整语速和音量并创建测试提醒；
- 本地模型目录、运行时目录联接和安装脚本具备完整性检查。

## 运行边界

- 所有语音文本和 WAV 合成都在本机完成；
- 本地语音不会把提醒内容发送给 MiMo、DeepSeek 或其他云端服务；
- 原始模型保存在 `.data/voice/`，该目录不进入源码版本控制；
- 为兼容部分语音运行库对中文路径的限制，安装脚本只创建
  `C:\tmp\jarvis-voice-model` 和 `C:\tmp\jarvis-voice-en-model` 目录联接，
  不复制或移动模型；
- 首次加载模型会占用额外内存，当前配置固定使用 2 个 CPU 线程；
- 所需本地男声不可用时自动退回 Windows 系统声音；
- 英语男声模型卡注明训练数据采用 CC BY-NC-SA 4.0，本项目仅用于个人、
  非商业用途，不应直接用于商业发布；
- 其他模型及依赖再分发或商业使用前同样需要单独复核上游许可。

## 安装

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-voice.ps1
```

脚本会检查 Python 运行时，按需下载中英文两个模型，验证必要文件，并创建兼容
目录联接。重复执行不会重复下载完整模型。

## 验收结果

- 运行时状态：中文男声、英语男声、双语链路和 Windows 备用语音全部可用；
- 试听文件：单声道、16 kHz、约 8.85 秒；
- 英语试听：单声道、22.05 kHz、约 3.63 秒；
- 中英混合试听：单声道、22.05 kHz、约 5.10 秒；
- API 与 Desktop Companion 定向测试：10 项通过；
- 离线合成未调用云端模型，也未占用独立显卡。
