# Sprint 17：个人模型评测与隐私化执行追踪

日期：2026-07-29

## 目标

用真实个人场景比较 MiMo、本地 Qwen 和 DeepSeek 的质量、速度与稳定性，同时
让每次模型调用可检查、可反馈，但不在审计记录中复制私人对话和知识正文。

## 已完成

- 新增“模型评测”页面；
- 建立 6 项固定个人测试：日程规划、知识引用、情报不确定性、投资安全、
  未知信息诚实性和英语指导；
- 每项测试可以独立选择 MiMo、本地 Qwen 或 DeepSeek；
- DeepSeek 测试继续要求逐次确认费用，测试系统不能绕过；
- 未配置的模型不能运行测试，也不会自动降级到其他模型污染对比结果；
- 测试记录回答、规则检查、得分、总耗时、首字耗时、Token 和生成速度；
- 模型概览按 Provider 汇总真实调用数、成功率、首字速度、测试得分和用户反馈；
- 最近模型调用新增“有帮助 / 没解决”反馈；
- 最近模型调用可以查看“选择模型 → 检索知识 → 生成回答”的安全执行过程；
- 执行过程只展示路由、模型、耗时、Token、引用数量和错误类型；
- 原有 MiMo 主路由、DeepSeek 付费确认、本地隐私处理和知识云权限保持不变。

- 数据库迁移版本：`20260729_0017`。

## 隐私边界

- 评测只使用项目内固定、非私人测试题；
- 执行追踪不保存新的用户提问副本、回答副本或 Obsidian 摘录；
- 知识检索只记录数量、字符数、查询哈希和内部文档 ID；
- 页面不显示 Provider 原始错误正文，避免错误信息意外携带内容；
- API Key 仍只从本机 `.env` 读取；
- 评测结果不会自动修改正式路由；
- 反馈当前只用于统计，不会取消任何人工确认和安全规则。

## 使用流程

1. 打开侧边栏“评测”；
2. 选择 MiMo、本地 Qwen 或 DeepSeek；
3. 选择一项能力测试并运行；
4. 查看得分、检查项、回答与速度；
5. 标记“符合预期”或“不符合”；
6. 使用同一测试题切换另一个模型进行对比；
7. 在“设置 → 最近模型调用”查看日常对话的安全执行过程。
