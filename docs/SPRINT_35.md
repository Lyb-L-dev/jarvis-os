# Sprint 35：Personality Layer

## 状态

已完成。Jarvis 现在有稳定的人格定义：称呼、语气和表达习惯在中文与英文中保持一致，并明确写入“人格不能覆盖事实、安全规则和用户最新要求”的边界。人格设置可通过页面调整并立即生效。

## 目标

- 建立稳定的 Jarvis 人格、称呼、语气和表达习惯；
- 中文与英文人格保持一致；
- 人格不能覆盖事实、安全规则和用户最新要求。

## 已交付

### 人格定义（`services/personality.py`）

- 单一事实来源：`Jarvis` 身份、称呼规则、三种语气（自然平和/轻松自然/正式克制）、表达习惯（先给结论、直接诚实、不奉承、不确定时说明、不展示隐藏推理、跟随用户语言）；
- 中文与英文双版本提示词块，规则一一对应；
- 边界块（永远优先于人格）：事实与安全规则优先、不展示隐藏推理、不编造事实、不执行投资交易/支付/凭据操作/不可恢复删除、犯错直接更正；
- 用户最新要求（额外规则）以最高优先级追加在提示词末尾。

### 人格设置（用户偏好）

- `user_preferences` 新增 `personality_settings` JSON 字段（迁移 0028）：称呼、语气、是否允许表情符号、最多 8 条额外表达规则；
- 设置经过 Pydantic 校验：称呼去空格限 32 字、规则去空行限 200 字、语气枚举校验。

### 接入链路

- 聊天：`system_prompt(user)` 改为调用 `build_system_prompt`，人格块进入每次对话的系统提示词（并继续受 Sprint 34 上下文预算约束）；
- 英语教练：`coach_system_prompt` 支持注入英文人格行（诚实、不臆造错误、以最新消息为最高优先级），路由按用户偏好生成；
- 人格不改变检索、路由、审批等任何功能逻辑。

### Personality API（`/api/v1/personality`）

- `GET /personality/overview`：当前设置、中英文提示词预览、边界列表、说明；
- `PUT /personality/settings`：保存设置并返回最新预览；
- `POST /personality/preview`：按指定语言与设置生成预览（不保存）。

### Personality 页面

- 侧边栏 SYSTEMS 分组新增入口，地址 `/personality`；
- 人格设置表单：称呼、语气三选一、表情符号开关、额外规则（每行一条）；
- 中/英文提示词预览面板，保存或预览即时刷新；
- 边界面板：四张“人格不能覆盖”卡片；
- 说明横幅：人格只影响表达，冲突时以事实、安全规则和最新要求为准；
- 视觉验收截图：`artifacts/personality-layer-sprint35.png`。

## 设计说明

- 人格是“表达层”，不是“行为层”：不改变路由、检索、审批与安全边界；
- 中英文人格由同一份规则生成，避免两套提示词漂移；
- 用户最新要求（额外规则）优先级最高，但仅限表达习惯，不能覆盖安全规则；
- 人格块随上下文预算截断，超长时优先保留边界与最新要求部分。
