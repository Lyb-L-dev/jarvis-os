# Jarvis OS v1.1 无隐私演示指南

## 创建演示数据

先启动 Jarvis，然后在项目目录运行：

```powershell
.\scripts\demo-data.ps1
```

脚本会创建一组明确标记为 `[DEMO]` 的虚构数据：

- 一个长期目标和一个里程碑；
- 一个已完成任务和一个待办任务；
- 一条仅本地长期记忆；
- 一条虚构情报；
- 一个虚构资产、持仓、分红、投资理由和事实复盘；
- 情报与虚构资产的关联。

不会创建真实提醒，不会调用云端模型，也不会使用私人数据。

演示结束后运行：

```powershell
.\scripts\demo-data.ps1 -Remove
```

脚本只删除其状态文件中记录的演示对象，不会按名称批量删除，也不会修改原有
个人数据。

## 建议演示路线

1. 总览：介绍“本地优先、电脑优先、持续成长”的定位；
2. 成长：展示目标、任务、实际投入和进度依据；
3. 情报：展示来源事实、AI 分析与转任务；
4. 投资：展示手动持仓、投资理由、关联情报和“不构成投资建议”；
5. 英语：展示纠错需要用户确认，再进入错题与复习；
6. 记忆：展示只使用已确认记忆，云端权限单独控制；
7. 提醒：展示桌面、语音、免打扰、延迟和投递历史；
8. 设置：展示本机监听、模型审计、自动备份、恢复验证和数据导出。

## 五分钟演示视频脚本

### 0:00–0:30 开场

“Jarvis OS 是我为长期个人使用设计的本地优先 AI 操作系统。它不是一个只有
聊天框的助手，而是把目标、任务、英语、情报、投资记录、长期记忆和主动提醒
连接成可审计的个人闭环。”

### 0:30–1:15 成长闭环

打开成长页：

“每个目标可以拆成里程碑和任务。计划先生成草稿，确认后才修改安排。进度和
周复盘来自真实完成状态与计时记录，不由模型凭空编造。”

### 1:15–2:00 情报与行动

打开情报页：

“情报只来自白名单 RSS 或手动来源。页面把来源事实、整理摘要、分析和建议行动
分开显示。收藏、忽略和转任务会反馈到兴趣权重，投资内容不会生成买卖指令。”

### 2:00–2:45 投资复盘

打开投资页：

“资产、交易和最新价格由我手动录入。数量和金额使用定点数计算，历史交易变化
会重算后续成本。情报可以关联持仓，但系统不接券商、不自动交易，也不预测价格。”

### 2:45–3:30 英语、记忆与提醒

依次打开英语、记忆和提醒页：

“英语纠错先确认，再进入错题和间隔复习。长期记忆也必须确认，密码、验证码和
API Key 会被拦截。到期事项由独立 Windows 组件通过桌面和语音主动提醒。”

### 3:30–4:20 模型与隐私

打开设置页模型审计：

“普通请求设计为 MiMo 主导，复杂问题可以手动确认后使用 DeepSeek，敏感和离线
请求使用本地 Qwen。云端失败会降级本地模型，不会自动产生 DeepSeek 费用。”

### 4:20–5:00 数据保护与结尾

展示恢复点和数据导出：

“Jarvis 自动创建 PostgreSQL 恢复点，并在独立临时数据库中验证可恢复性。网页
不提供覆盖恢复按钮，避免误操作。OpenClaw 微信接入因为插件缺少独立沙箱而延期，
安全门槛没有满足之前不会安装到主力电脑。”
