# Sprint 18：Visual Identity 2.0

## 目标

把 Jarvis 从通用深色管理后台升级为具有独立辨识度的个人 AI 指挥界面，同时不
改变现有数据、安全边界和操作流程。

本阶段只借鉴电影级 HUD 的信息层次、空间感和反馈方式，不复制电影商标、演员
声音或现成视觉资产。

## 已完成

### 原创 J-Core 视觉标志

- 新建原创的环形核心标志，由分段外环、六边形内核、J 轴和信号节点组成；
- 同一标志用于网页图标、侧边栏品牌和中央核心；
- 替换原有字母方块图标，保留深色、青色和高对比视觉语言；
- 图形以 SVG 和 CSS 实现，可无损缩放，不依赖外部图片或网络资源。

### 五种核心状态

中央核心提供五种清晰可区分的反馈：

| 状态 | 含义 | 视觉反馈 |
|---|---|---|
| 待命 | 系统在线，等待输入 | 缓慢呼吸和稳定环形扫描 |
| 聆听 | 已进入输入接收状态 | 青色波纹和增强脉冲 |
| 思考 | 正在读取、检索或推理 | 紫色反向旋转与轨道变化 |
| 执行 | 正在同步或运行操作 | 绿色快速扫描 |
| 警报 | 核心依赖异常或读取失败 | 红色警示脉冲 |

总览首次加载时自动显示“思考”，手动同步时显示“执行”，核心依赖异常时显示
“警报”。状态预览按钮只改变视觉反馈，不会触发模型调用或其他真实操作。

### 实时指挥总览

旧总览中的演示数字已经移除，当前页面读取并展示：

- 今日成长任务、完成进度和剩余时间容量；
- MiMo 主路由、已配置模型数量和核心依赖状态；
- 本周实际投入、未读情报、有效长期记忆和投资持仓；
- 英语复习、情报兴趣、知识数量和可用模型形成的个人信号矩阵；
- 基于真实任务状态给出的当前建议。

任何单个模块读取失败都不会阻塞整个总览；核心就绪检查失败时会进入警报状态。

### 导航与视觉系统

- 侧边栏按核心、行动、情报和系统分组；
- 全部导航入口使用统一的原创线框图标；
- 增加核心在线反馈、扫描线、激活信标和精细边界层次；
- 新增统一颜色、间距、字体、发光和动画设计令牌；
- 尊重系统的“减少动态效果”设置；
- 在较窄的电脑视口下压缩中央核心和三栏间距，不影响既有模块页面。

## 安全与兼容性

- 没有新增数据库表或迁移；
- 没有改变 MiMo、DeepSeek 或 Ollama 路由；
- 没有新增外部字体、图片、脚本或追踪服务；
- 没有开放局域网、平板或 OpenClaw 接口；
- 没有改变现有投资、记忆、知识库和提醒的权限规则；
- 侧边栏宽度保持兼容，复杂工作页将在 Sprint 19 逐页升级。
