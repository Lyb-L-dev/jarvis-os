# Sprint 22：投资与国际动态监控中心

状态：**核心闭环已实现并通过本机验收**

## 目标

把现有的投资记录、公开情报与主动提醒连接起来，使 Jarvis 能回答：

1. 最近发生了什么可追溯事件；
2. 它为什么可能与某个资产、投资理由或国际主题相关；
3. 影响方向、强度与传导路径目前能否确定；
4. 接下来需要核对什么，而不是给出买卖指令。

## 已实现

- 独立的 `/monitoring` 监控中心；
- 资产、宏观与国际动态三类监控项；
- 资产监控可绑定已录入资产及当前投资理由；
- 关键词、地区、影响渠道、最低提醒等级和暂停控制；
- 每五分钟检查到期来源，来源仍遵守各自刷新间隔；
- 对最近有来源链接的情报进行确定性匹配；
- 生成事实摘要、相关原因、可能传导路径、影响方向、影响等级和下一步观察；
- 自动建立情报与资产的可审计关联；
- 高于阈值的事件进入桌面和语音提醒；
- 每个事件幂等、每个监控项带冷却时间，不重复轰炸；
- 事件可以“已确认”或“忽略”，原始情报不会被修改；
- 自动扫描后台任务、手动立即扫描和运行状态总览；
- 桌面与平板浏览器均可访问，计算和数据仍留在电脑端。

## 数据与安全边界

- 监控结果不构成投资建议，不自动交易；
- 不生成买入、卖出、调仓、仓位或价格预测；
- 单一来源只能生成待复核影响，不能当成已证实因果；
- 原始来源 URL、来源名称、发布时间和抓取时间全部保留；
- 价格仍是手工录入或明确带来源与时间的数据，不标注“实时行情”；
- 资产事件被视为敏感提醒，语音播报受全局隐私设置和静默时段控制；
- 当前规则分析不把持仓与投资理由发送给云端模型；
- DeepSeek 不参与自动扫描，避免付费调用和未经确认的深度推理。

## 来源策略

首批继续复用情报中心的官方白名单来源，重点包括：

- [Federal Reserve RSS](https://www.federalreserve.gov/feeds/feeds.htm)：货币政策、监管与统计公告；
- [United Nations News](https://news.un.org/en/)：国际事件与联合国公开动态；
- 公司或机构官方新闻源，例如 NVIDIA 官方博客；
- 用户手动保存且能打开原文的公开链接。

SEC EDGAR 后续可以按资产的 CIK 建立公司公告监控，但接入时必须遵守
[SEC Developer Resources](https://www.sec.gov/about/developer-resources) 的身份标识与访问频率要求。
欧洲宏观来源可在下一批加入 [ECB 官方 RSS](https://www.ecb.europa.eu/home/html/rss.en.html)。

## 暂不伪装成已完成的能力

- 没有购买或配置市场数据服务，因此没有实时股票行情；
- 没有可靠的 CIK/证券代码映射前，不自动抓取 SEC 公司文件；
- 当前影响分析是保守规则版 `rules_v1`，后续可在用户逐项授权后使用 MiMo 丰富分析；
- “正面/负面”表示事件文本中的初步影响信号，不代表收益预测。
