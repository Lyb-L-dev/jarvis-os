# Sprint 13：Obsidian 受控归档

日期：2026-07-29

## 目标

在 Jarvis Core 仍为唯一业务事实来源的前提下，把已经确认或已经完成的内容
安全归档到 Obsidian。任何用户修改都不能被 Jarvis 静默覆盖。

## 已完成

- 已确认且有效的长期记忆自动归档到 `Jarvis/Memory/`；
- 状态为 ready 的每日情报自动归档到 `Jarvis/Intelligence/Daily/`；
- 周复盘、已完成英语会话、投资理由和投资复盘进入手动归档候选；
- 新增来源唯一键和内容哈希，同一来源重复执行不会重复建文件；
- Jarvis 来源变化且目标文件未被用户修改时，安全更新原文件；
- 用户修改、文件缺失或首次目标冲突时不覆盖原文件；
- 冲突的新版本写入 `Jarvis/_review/`，并在知识库页面提示；
- 所有归档结果保存状态、目标路径、审核路径、时间和同步日志；
- 后台定时检查自动归档，Vault 不可用时不影响其他 Jarvis 模块；
- 知识库页面支持自动同步、手动归档、候选数量和冲突状态查看。

## 当前边界

- PostgreSQL 是记忆、情报、成长、英语和投资数据的唯一事实来源；
- Obsidian 是可阅读、可搜索、可审计的知识归档层；
- 自动写入仅限已确认长期记忆和已完成每日情报；
- 周复盘、英语和投资必须由用户点击归档；
- Jarvis 不访问 `.obsidian`、Vault 其他目录、链接或越界路径；
- 当前不依赖 Obsidian 插件、MCP、n8n 或向量数据库。
