# Sprint 19：Cinematic Command Interface

## 目标

把 Sprint 18 建立的 J-Core 视觉语言从总览扩展到实际工作流，让 Jarvis 在
“查看状态、进入模块、执行任务、确认安全边界”几个环节使用同一套指挥界面。

本阶段不重写已经稳定的业务表单和接口，而是在它们之上建立共享的状态层、模块
层次和交互反馈。

## 已完成

### 共享模块遥测

新增 `CommandTelemetry` 共享组件，每个核心模块用四个只读信号显示当前上下文：

- 当前视图或运行模式；
- 主要任务、数据或队列数量；
- 模型、来源或知识连接状态；
- 模块特有的隐私与安全边界。

遥测只读取页面已经加载的数据，不会产生额外模型调用，也不会修改业务记录。
每种状态采用统一的青、绿、紫、黄、红反馈颜色。

### Chat 指挥入口

对话页现在直接展示：

- Jarvis 当前处于待命还是执行状态；
- 当前选择的模型路线；
- 当前对话消息数量以及是否启用摘要上下文；
- 隐私模式、知识库增强或标准边界。

同时完成：

- 欢迎核心由旧字母图标替换为原创 J-Core 动态核心；
- 助手消息头像统一使用 J-Core；
- 输入区升级为命令输入台，但保留 Enter、停止、模型、隐私和知识库操作；
- 对话列表、消息气泡和顶部状态采用统一线框与信号边界；
- 没有改变自动保存、流式回答、停止、重新生成和知识沉淀逻辑。

### 核心工作页

下列页面已经接入统一遥测与 Cinematic 视觉层：

| 页面 | 主要遥测 |
|---|---|
| 成长 | 当前视图、每日容量、今日任务、本周投入 |
| 英语 | 训练模式、会话记录、到期复习、待确认纠错 |
| 情报 | 整理路线、来源状态、未读信号、每日情报 |
| 投资 | 当前视图、持仓、交易记录、人工决策边界 |
| 记忆 | 全部记忆、有效记忆、确认队列、受控写入 |
| 知识库 | Obsidian 连接、笔记数量、草稿队列、云端授权 |

所有统计卡、视图切换、主操作按钮、表单控件和内容面板进一步统一为细边界、
切角、扫描线和本地字体系统。复杂内容仍保持较高可读性，没有把表单变成纯装饰。

### 可访问性与性能

- 动画仍遵守系统“减少动态效果”设置；
- SVG、CSS 和界面组件均为本地资源；
- 新遥测不发起额外 API 请求；
- 较窄电脑视口会自动压缩遥测文字和间距；
- Chat 的滚动消息区与固定输入区在增加状态层后仍保持独立可用。

## 未改变的边界

- 未新增数据库迁移；
- 未修改 MiMo、DeepSeek 和 Ollama 路由；
- 未改变 DeepSeek 逐次付费确认；
- 未改变投资、不可信知识、记忆和 Obsidian 权限规则；
- 未开放局域网、平板、微信或 OpenClaw 接口；
- 未增加外部字体、图片、分析服务或第三方前端依赖。
