## 浏览器验收

以下流程均为真实 Edge 浏览器、真实 API 和真实 PostgreSQL；验收对象均精确清理：

1. 成长目标 → 里程碑 → 每日计划 → 任务生命周期 → 周复盘；
2. 对话记忆 → 用户确认 → 编辑 → DeepSeek 费用确认取消；
3. 提醒创建 → 延迟 → 忽略 → Windows 桌面投递 → 历史清理；
4. 官方情报源 → 分层简报 → 收藏 → 转成长任务；
5. 英语会话 → 纠错确认 → 错题 → 到期复习 → 下次提醒；
6. 资产与持仓 → 分红 → 投资理由 → 关联情报 → 事实复盘；
7. 恢复点状态 → 恢复验证 → 个人数据导出。

## 风险与后续

1. 把已验证恢复点复制到移动硬盘，解决同盘故障风险；
2. 如果 Windows 账户由多人共用，先收紧 `.env` ACL 或改用单独账户；
3. 在第二台全新 Windows 电脑按 `USER_GUIDE.md` 做一次安装复现；
4. OpenClaw 只有在虚拟机隔离和插件审计全部通过后才恢复；
5. MiMo Token Plan 已按所有者要求启用；小米当前套餐说明仍包含非编程自定义
   后端限制，可能暂停服务或封禁密钥。若不接受该风险，将显式开关改回 `false`，
   或换用允许应用后端调用的按量 API 密钥。
