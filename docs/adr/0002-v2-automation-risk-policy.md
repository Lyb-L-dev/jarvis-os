# ADR-0002：自动化风险与不可委托权限

- 状态：接受
- 日期：2026-08-02
- 适用版本：Jarvis OS v2.0

## 背景

Jarvis 将逐步接入文件、日历、邮件、浏览器和外部账号。模型生成的工具调用不能等同于用户授权。

## 决策

所有动作必须先由确定性的 `RiskPolicy` 分类：

| 等级 | 范围 | 处理方式 |
|---|---|---|
| R0 | 读取本地数据、公开来源、检索知识 | 可以自动执行 |
| R1 | 生成草稿、保存到 Jarvis 内部草稿区 | 可以自动执行 |
| R2 | 修改文件、日历、邮件、外部账号、浏览器提交 | 展示预览并逐次确认 |
| R3 | 投资交易、支付、删除数据、凭据操作 | Agent 永不执行 |

R3 是不可委托权限。它不能通过 Prompt、AgentSpec、管理员开关或普通审批转换成可执行动作。用户仍可在相应官方产品中自行完成合法操作。

## 结果

- R2 的审批只覆盖预览中列出的资源和一次运行；
- 用户拒绝后不得改用其他 Agent 或工具绕过；
- 模型负责提出候选动作，Policy 层拥有最终否决权；
- 后续 Tool Gateway 必须复用这套分类，而不是自建宽松规则。

## 草稿区边界

“自动保存草稿”仅指 Jarvis 自己管理的草稿存储。把草稿写入普通文件、Obsidian 既有笔记、邮箱、日历或外部服务仍属于 R2。
