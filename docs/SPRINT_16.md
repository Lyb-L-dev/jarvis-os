# Sprint 16：本地知识提炼与复用

日期：2026-07-29

## 目标

把用户已经确认值得整理的知识草稿，进一步拆成可复用的长期记忆、行动任务和
待核验问题，同时保留人工确认、来源追踪和本地优先边界。

## 已完成

- 知识草稿新增“提取记忆与行动”入口；
- 提炼固定使用本地 Ollama Qwen，不调用 MiMo 或 DeepSeek；
- 本地模型严格返回最多 8 条结构化候选；
- 候选只允许长期记忆、行动任务和待核验问题三种类型；
- 知识库页面逐条显示候选类型、草稿来源、内容和提炼理由；
- 长期记忆必须人工确认，确认后状态有效且默认不允许云端使用；
- 行动候选确认后创建普通成长任务；
- 待核验问题确认后创建带“核验：”前缀的成长任务，不当作事实；
- 忽略候选不会写入记忆或任务；
- 提炼、候选内容和确认动作具备幂等保护；
- 敏感凭据沿用长期记忆安全规则，不能通过候选进入记忆；
- 修改草稿会删除未接受候选并允许重新提炼，已接受结果继续保留；
- 已归档但尚未提炼的草稿仍保留提炼入口；
- 模型或 JSON 解析失败会写入失败审计，但不生成候选或标记提炼完成。

## 数据与来源

- 新表：`knowledge_insight_candidates`；
- 草稿新增：`insights_extracted_at`；
- 每条候选保留 `capture_id`、来源标题、内容指纹和确认状态；
- 接受后保存可选的 `memory_id` 或 `task_id`，可以回溯实际生成结果；
- 同一草稿内相同类型和内容只能形成一条候选；
- 已存在的有效记忆或未完成任务会被复用，不创建重复记录。

## 安全边界

- 不后台扫描历史对话或历史草稿；
- 不自动调用提炼接口；
- 不自动接受任何候选；
- 草稿按不可信数据处理，不执行其中的指令、链接动作或权限要求；
- 不补充外部事实，不把猜测改写成事实；
- 不允许本地提炼失败后自动降级到云端；
- 待核验问题永远先成为核验任务，而不是确认记忆；
- 接受记忆仍执行 API Key、密码、验证码、证件号、银行卡和私钥拦截。

## 使用流程

1. 在 Chat 点击“沉淀知识”，等待本地 Qwen 生成草稿；
2. 在知识库页面检查并修改草稿；
3. 点击“提取记忆与行动”；
4. 逐条保存长期记忆、创建成长任务、创建核验任务或忽略；
5. 如需保留完整知识原文，再确认写入 Obsidian；
6. 需要云端模型使用归档笔记时，仍需对该笔记单独开启“允许云端”。
